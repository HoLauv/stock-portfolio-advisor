# A 股价值分析 skill 优化审查

审查日期：2026-09-05。基于当前 SKILL.md、评分引擎与指标映射。本文是模型设计建议，不是个股投资建议；尚未修改评分算法，也未验证数据服务的实际可用性。

## 结论

确定性计算、快照追踪和离线报告是良好的基础。主要短板是把投资价值、市场热度和交易位置混为同一结论，以及缺少数据质量门槛。应先修正口径和实现错误，再引入分行业估值与情景区间，最后通过历史检验校准参数。

## 怎样使估值更合理

### 1. 先明确所估的价值与期限

分别输出“估值日公允价值”“未来12个月情景价格”“技术压力位”。若以未来利润计算未来目标价，标明对应年度；需转换为今天的价值时，按匹配风险的回报要求折现并正确处理期间分红。不要把不同期限的数字直接平均。

### 2. 按企业经济特征选方法

| 企业类型 | 主方法 | 交叉验证与限制 |
| --- | --- | --- |
| 盈利稳定的消费、制造企业 | 正常化利润×可比PE；现金流可预测时用DCF | 剔除非经常性项目，检查现金转化、ROIC和资本开支；历史PE中位数不是天然合理PE |
| 煤炭、有色、化工等周期企业 | 完整周期正常化利润/现金流；适用时EV/EBITDA | PB只作资产质量交叉验证，不能假定破净就便宜；考虑减值、商品价格和资本开支周期 |
| 银行 | 可持续ROE驱动的PB、股利折现或剩余收益 | 稳态条件下PB=(ROE-g)/(Ke-g)，要求Ke>g，且ROE、分红和增长一致；检查不良资产与资本约束 |
| 保险 | 分业务估值，内含价值等适用指标辅助 | 检查资本、业务结构及假设敏感性；不套银行拨备覆盖率 |
| 券商 | 正常化ROE/PB，业务分部估值 | 不能把牛市利润外推；考虑自营、经纪、投行和资本约束 |
| 成长或亏损企业 | 收入、利润率、再投资与稀释驱动的情景DCF；可比EV/Sales辅助 | 给出达到盈利的路径、现金消耗和融资需求；没有可信预测时只给条件情景，不硬算目标价 |
| 公用事业、成熟红利企业 | 可持续股利/自由现金流折现 | 股息率不是充分估值依据，需检查分红覆盖、债务与维护性资本开支 |

周期公司应使用覆盖完整周期的盈利口径，同时考虑恢复到正常水平所需的时间，不能假设立即恢复。参考：[Damodaran：正常化盈利](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/normearn.htm)。金融企业的现金流、债务及资本监管具有特殊性，参考：[金融服务企业估值](https://pages.stern.nyu.edu/~adamodar/pdfiles/country/finsvce.pdf)。

### 3. 用情景区间呈现不确定性

为保守、基准、乐观三种情景逐项记录收入、利润率、资本开支、折现率、终值增长和股本。区间来自经营假设，而不是对单点价格机械加减20%。模型间分歧大时解释原因，不能自动删除低估值结果。

如果没有可辩护的情景概率，直接展示区间和基准值，不制造概率加权的精确感。安全边际可定义为 `1-现价/公允价值`，与 `公允价值/现价-1` 的上行空间分开显示；折价门槛应与风险、证据质量及历史检验关联，不固定承诺收益。

### 4. 数据与单位必须可追溯

每项输入增加来源、抓取时间、公告日期、报告期、单位、实际/预测属性和缺失原因。统一归母/扣非口径、股本与复权处理；DCF由企业价值到股权价值时核对净债务、少数股东权益、非经营资产及潜在稀释。

一致预期需保存机构数、独立机构去重、时间窗口、预测年度、分歧与修正趋势。当前代码只接收一个数，无法自行验证“至少3家、近90日”的要求。

北向数据不能默认沿用历史披露频率。上交所已调整相关披露机制，参见[交易所公告](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20240412_10753188.shtml)。应逐字段核查供应商覆盖和时间粒度；不可获得的20日指标应禁用或换用可验证指标，不能用估算值冒充原始净流入。

### 5. 评分与配置分开

保留质量、成长、估值作为价值判断，另列资金、趋势、情绪作为交易环境。权重可作为待检验参数，而非拍脑袋给一组新的“最优比例”。

配置先读取风险承受度、投资期限、现金需求、总资产分母、其他资产及可承受回撤。现有“冰点95–100%权益”不能只由市场温度决定，还与至少5%现金要求存在边界冲突。加入流动性、停牌/涨跌停、交易费用、最小交易单位和产业链相关性约束。

### 6. 用历史检验校准，而非追求目标价命中

按公告可得时点构建滚动样本，包含退市股票，避免未来信息和幸存者偏差。保留训练期、验证期及独立测试期，跨行业和牛熊周期检验；计入分红、复权及交易成本。

评价维度包括未来12/24个月含分红收益分层、回撤、行业偏差、换手、参数敏感性及估值偏差诊断。市场价格不是真实内在价值，情景价格区间的覆盖率只能检验市场预测校准，不能证明公允价值正确。没有历史检验，不宣称新方法更赚钱。

## 建议落地顺序

1. 修复P0与单位口径，建立缺失数据门槛，并为这些反例建立回归检查。
2. 增加估值路由、基本面情景区间与假设表；同步引擎、报告、输入模板和说明。
3. 建立时点数据与历史检验，再决定权重、阈值和安全边际。

建议输出字段：`valuation_as_of`、`horizon`、`method`、`fair_value_bear/base/bull`、`assumptions`、`sources`、`coverage`、`confidence_reason`、`excluded_methods`。这些为设计建议，当前版本尚未实现。
